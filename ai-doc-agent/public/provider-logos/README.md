# Provider logo assets

These SVG assets are vendored from the maintained
[`@lobehub/icons-static-svg`](https://www.npmjs.com/package/@lobehub/icons-static-svg)
library, version `1.94.0`.

The filenames are normalized for TEK-DOK-MIND connector identifiers. Update
them from the library when provider branding changes; do not replace them with
hand-drawn approximations.
